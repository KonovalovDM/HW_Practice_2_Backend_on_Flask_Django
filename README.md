## Ветка main_3
Задача 3. Потоки

В этой задаче тренируемся в работе с многопоточностью в Python (threading). <br>
Необходимо создать и запустить потоки, передать аргументы в потоковую функцию и дождаться их завершения.<br>
Это поможет понять, как выполнять блокирующие операции параллельно.

Представляем, что у нас есть CPU-независимая, но блокирующая операция, которую мы хотим выполнить параллельно.<br>
Используем threading.

    Создаем функцию long_task(name), которая использует time.sleep() и выводит результат.
    Запускаем два потока с разными аргументами.
    Дожидаемся завершения всех потоков.


## Ветка main_4
Задача 4. Класс Semaphore

Семафоры (threading.Semaphore или asyncio.Semaphore)<br>
Позволяют ограничивать количество потоков/корутин, одновременно выполняющих
определенный участок кода.<br>
В этой задаче семафор применяется для контроля доступа к общему ресурсу,
чтобы избежать конкуренции и перегрузки системы.

    Создаем asyncio.Semaphore(2) — максимум 2 задачи одновременно.
    Создаем 5 корутин, которые запрашивают доступ и «работают» 2 секунды.
    Все корутины запускаем одновременно, но выполняються не более 2 корутин за раз.
